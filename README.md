# MindSense AI
Animated frontend prototype inspired by the supplied dark biodiversity-style reference.

Open `index.html` with VS Code Live Server.

This version contains the visual experience, smooth scrolling, layered CSS landscape, animated waterfall/deer scene, color wellness theme, login modal, weekly check-in and dynamic demo snapshot.

For the full academic project, connect the UI to Flask + SQLite + scikit-learn + NLP + explainable AI as described in the project prompt.
